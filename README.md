# Bánh Mì Thơm Ngon

Web ghi sổ bán bánh mì cho người bán hàng ven đường (1–3 người).

- Không cần đăng nhập, không cần mật khẩu
- Bấm 1 nút = bán 1 ổ
- Chạy được khi mất mạng (CSS nhúng sẵn trong file)
- Sổ theo ngày / tháng, bấm vào một ngày để xem chi tiết
- Xuất Excel, sao lưu / phục hồi dữ liệu

## Đưa lên mạng bằng GitHub Pages

1. Vào **Settings** → **Pages**
2. Mục **Source** chọn **Deploy from a branch**
3. **Branch** chọn `main`, thư mục `/ (root)` → **Save**
4. Chờ khoảng 1 phút, web có tại:
   `https://<tên-tài-khoản>.github.io/<tên-repo>/`

Mọi dữ liệu lưu trong trình duyệt của máy đang dùng (localStorage).
